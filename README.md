# Webfox

Webfox, öğrenciler ve eğitmenler için tasarlanmış Türkçe bir edtech SaaS başlangıç projesidir. İlk sürüm, öğrenme platformunu tanıtan responsive bir landing page ve etkileşimli kurs keşif alanı içerir.

## Teknoloji
- Next.js 15 ve React 19
- TypeScript
- Özel responsive CSS
- Lucide ikonları

## Yerelde çalıştırma

```bash
npm install
npm run dev
```

Tarayıcıda [http://localhost:3000](http://localhost:3000) adresini açın.

## İlk sürümde
- Türkçe edtech landing page
- Öğrenme paneli önizlemesi
- Kurs kategorisi filtreleri
- Mobil navigasyon
- Platform, kurslar, referans, CTA ve üyelik bölümleri

Üyelik, ödeme, kimlik doğrulama ve gerçek kurs verileri henüz bağlı değildir; sonraki geliştirme adımlarında entegre edilebilir.
